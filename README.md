# Gringo: Green Mobility Dashboard 🌿

**Gringo** è una dashboard intelligente per la gestione della mobilità urbana sostenibile (Smart City).  
Il progetto permette di monitorare in tempo reale una flotta di veicoli elettrici comunali, gestire le stazioni di ricarica e coordinare gli interventi di manutenzione tecnica.

## 🚀 Funzionalità Principali
- **Dashboard Operativa:** KPI e grafici interattivi sull'utilizzo dei mezzi e il risparmio di CO2.
- **Mappa Interattiva:** Geolocalizzazione in tempo reale di veicoli (auto, bici, monopattini) e stazioni.
- **Gestione Flotta:** CRUD completo per stazioni e mezzi con filtraggio avanzato per stato.
- **Supporto Tecnico:** Sistema di ticketing per la segnalazione guasti e la pianificazione di interventi.

## 🛠️ Tech Stack
- **Frontend:** React + Vite + Tailwind CSS + MapLibre GL
- **Backend:** Laravel 11 + MySQL
